# Jekyll site (migrated)

This Jekyll site was generated from your WordPress export.

How to use:
1. Update `_config.yml` (site.url, author, etc).
2. Commit this folder to a repository named `username.github.io` (or any repo and enable GitHub Pages from `main`/`gh-pages` branch).
3. GitHub Pages will build the site automatically (it uses Jekyll).

Notes:
